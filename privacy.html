Privacy information

Atlas Evidence Services is a personal, owner-operated tool for maintaining a private evidence collection. This page describes the Google Drive connection and the public information website.

Information accessed

With the owner's authorization, the tool may access Google Drive file and folder names, identifiers, paths, sizes, timestamps, available checksums, and file contents. Recovery archives can include database exports, server configuration, local files, and credentials protected inside encrypted bundles.

Purpose and storage

Google Drive data is used to maintain and verify owner-directed copies, store and recover backups, and record document provenance and processing results. Metadata, processing records, and extracted text may be stored in the owner's PostgreSQL database. Files are held in the owner's cloud accounts and, where needed, on the private server.

Sharing and AI

The tool does not sell Google user data, use it for advertising, or use it to train generalized AI models. The current Google Drive connection does not provide document access to an external AI service. Any future AI retrieval integration requires a separately configured and owner-authorized connection and an update to these disclosures before that integration uses Google user data.

Google and Microsoft process the files stored with their respective services under their own policies. The operator's private server processes the records needed for the collection. This public website does not expose those records.

Retention and owner control

Source files and catalog records are retained according to the owner's collection and preservation decisions. Mirror deletions can remove destination files; separate recovery archives may retain earlier copies until the owner removes them under the backup retention policy. Automated retention is not yet configured.

The owner can revoke the application's access through their Google Account's third-party connections settings. Revocation stops future authorized access; it does not automatically erase existing local records or recovery archives. Those copies must be reviewed and deleted separately by the owner.

Security

Recovery bundles are encrypted before upload. Credentials are kept out of the public website and repository. Encryption recovery material must be held separately from the server. These measures do not guarantee against every loss or unauthorized access.

Google API commitments

Atlas Evidence Services' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This public website

The site contains no application analytics scripts, advertising, or document-upload form. GitHub Pages hosts it and logs visitor IP addresses for security purposes as described in GitHub's privacy statement.

Questions

Use the project's public GitHub issues for non-sensitive questions. Do not post private documents, credentials, or personal records there. The app owner's support email is also provided on Google's authorization screen.
